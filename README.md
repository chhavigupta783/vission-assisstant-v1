# 👁️ Vision Assistant v1.0.0

A custom desktop AI vision tool built from scratch using **Electron**, designed to bring instant, system-wide AI assistance directly to your desktop environment without the friction of constant context-switching.

---

## ✨ Features

- **⚡ Global Shortcut Activation:** Runs discreetly in the background and listens for the `Ctrl + Shift + Space` key combination, allowing you to trigger the assistant instantly from *any* active window or application.
- **🖥️ Native Desktop Experience:** Packaged smoothly as a standalone Windows application via `electron-builder`.
- **💬 Real-Time Chat & Vision:** Interact with AI models seamlessly right from your desktop.
- **🖼️ Multiple Screen Capture:** Allows you to seamlessly capture and analyze multiple screens or active display areas simultaneously, making it ideal for multi-monitor workflows and complex desktop tasks.
- **🧠 Memory Capabilities:** Remembers project contexts, user preferences, and implementation details across sessions, while tracking ongoing development workflows.
- **🎨 Voice & Theme Customization:** Includes voice and audio interaction features alongside a sleek dark/purple UI theme optimized for desktop environments.

---

## 📥 Installation & Setup Guide (Windows)

To get Vision Assistant running smoothly on your PC, please follow these installation steps carefully to prevent any missing runtime dependencies (such as `ffmpeg.dll`):

1. **Download the Package:**
   - Head over to the [Releases Page](https://github.com/chhavigupta783/vission-assisstant-v1/releases/tag/v1.0.0) and download the latest `.zip` package (`Vision.Assistant-1.0.0-win.zip`).

2. **Extract the Files (Important):**
   - **Do not** try to run the application directly from inside the compressed zip folder.
   - Right-click the downloaded zip file, select **"Extract All..."**, and choose your preferred destination directory.

3. **Launch the Application:**
   - Open the newly extracted folder and double-click **`Vision Assistant.exe`** to launch the app instantly.

## 🛠️ Quick Troubleshooting & Tips

- **Windows Defender / SmartScreen Warning:** 
  - If Windows warns you with *"Windows protected your PC"* when opening the `.exe` file, click on **"More info"** followed by **"Run anyway"** (this is common for custom, unsigned executable files).
- **API Keys / Configuration:** 
  - If the app uses a custom local server, `.env` file, or API key configuration, make sure your configuration files are placed in the same directory as the executable.

## 🚀 How to Use

1. Once the application is running, it will sit quietly in the background.
2. Press **`Ctrl + Shift + Space`** from anywhere on your desktop to bring up the Vision Assistant interface.
3. Type your prompt, ask questions, or interact with the app seamlessly!
